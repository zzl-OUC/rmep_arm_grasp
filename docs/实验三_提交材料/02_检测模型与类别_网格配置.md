# 目标检测方案、类别定义与桌面网格配置

对应提交要求第 2 项。源码：`arm_grasp_sim/scripts/vision_classifier.py`、`grid_mapper.py`。

## 1. 检测方案（仿真 = 传统视觉，无模型权重）

**方案 C：轮廓法检测 + 框内色相投票分类**，链路 `/top_camera/image_raw → /detections`。

| 环节 | 做法 | 关键参数 |
|---|---|---|
| 前景掩码 | HSV 的 S/V 阈值取"有颜色的像素"，白底与反光靠低饱和排除，灰色料盒被掩码天然滤掉 | `is_colored` |
| 连通域 | `findContours` + 外接框；CLOSE 用 **3×3** 核（只填 ≤1px 断裂） | `min_area=80`、`max_area=8000` |
| 分类 | 框内逐像素取色相，按类别色带投票，取多数类；同时输出 `dom_hue`、`sat_frac`、`votes` 到 `/vision_debug` | 见第 2 节 |

为什么 CLOSE 核不能大：6 个取物格在可达前弧内密集排布（格心间距 ~7.4 cm → 像空间只剩 ~10 px 间隙），核稍大就把相邻物体的彩色掩码连成一块，面积超 `max_area` 被**整块丢弃**（曾造成 0 检出的回归）。

**仓库内没有任何 `.onnx/.pt/.weights` 权重文件**，这是有意的：仿真物体是高饱和纯色，传统视觉足够且不需要训练数据。
但**真机不能沿用**：`config/classify_real.yaml` 明确要求 `use_yolo=true` 且 `class_from_yolo=true`，因为真机物体是"鼠标 + 网球"，鼠标多为黑/灰/白 → 低饱和 → 轮廓法连框都找不到，其所在网格会被误判成"空网格"（假空网格）。真机路线需自行放置检测权重。

## 2. 类别定义

```python
HUE_BOUNDS = {                 # OpenCV 色相域 0~179
    'tennis_ball': ((15, 78),),   # 荧光黄绿网球
    'bottle':      ((95, 130),),  # 高饱和蓝矿泉水瓶
}
UNKNOWN_CLASS = 'unknown'
```

- 网球渲染色 `diffuse=(0.85, 0.80, 0.10)` → hue≈56。旧边界 (18,45) 会把网球判成 unknown，故拓宽到 (15,78)。
- 78~95 之间留了绿/青 **guard band**，本场景无此色物体，用于把两类分开。
- `unknown` **必须作为一条 detection 发出去**：否则该物体在下游凭空消失，所在网格被误判成"空网格"。实验要求把"空网格"与"未识别物体"列为两类不同异常，分别记 `skipped_empty` 与 `skipped_unknown`。

类别 → 料盒映射（`classify_task_node.py` 参数 `class_bin_map`，与视觉无关，改映射不用重训）：

```json
{"tennis_ball": "bin_1", "bottle": "bin_0"}
```

## 3. 桌面网格配置

**格心坐标（三份必须一致：server `GRIDS`、`grid_mapper.CELLS`、launch `_NORMAL` spawn 位；另有 `_MISS`/`unknown_obj` 预设里各一份）**

```python
GRIDS = {
    'cell_1': ( 0.2250,  0.0000),   # 正前
    'cell_2': ( 0.1591,  0.1591),   # 左前 45°
    'cell_3': ( 0.1591, -0.1591),   # 右前 -45°
    'cell_4': (-0.2250,  0.0000),   # 正后
    'cell_5': (-0.1591,  0.1591),
    'cell_6': (-0.1591, -0.1591),
}
CELL_TOL = 0.075    # 归格半径(m)：0.16x0.10 格对角半径约 0.094，取 0.075 防相邻格重叠
```

半径 0.225 m 是 2026-09-21 应用户要求整体外移 4 cm 的结果。可达性依据见 `06_简要实验报告.md` 的包络表。

**相机与投影**：`top_camera` 位于 `(0,0,1.0)` 朝下，`hfov=0.95 rad`，图像 `800x640`。
`grid_mapper` 默认用理想针孔模型把像素反投影到桌面 z=0.025 平面（`fx=fy` 由 hfov/宽高推出，vfov 按宽高比换算）；也支持传入 3×3 **单应矩阵**（`homography` 参数，行主序 9 个数）优先于针孔模型——俯视场景用单应更准且免测 hfov/高度。标定工具：`scripts/pick_points.py`、`classify_calib.launch.py`。

**桌面与物体几何**（`worlds/table_grid_4c2b.world`、`urdf/`）

| 项 | 值 |
|---|---|
| 桌面 | `1.0 × 0.8 × 0.05`，顶面 z=+0.025 |
| 格垫 | `0.09 × 0.09 × 0.004`，随格心移动 |
| 料盒 | 正方 `0.29 × 0.29`，盒心 (0, ±0.24)；**近壁与两侧壁顶 z=0.040**，远墙顶 z=0.075；盒底面 z≈0.031 |
| 网球 | `tennis.urdf`，φ66 mm |
| 矿泉水瓶 | `bottle.urdf`，**φ55 × 高 100 mm**（2026-09-22 由 φ65 缩到 φ55；visual 圆柱与 collision 外接盒 `0.055 0.055 0.10` 两处必须同步改） |

料盒是 `<static>true</static>` 模型，因此盒子沿 y 外扩到 |y|=0.48 超出桌面边缘只是视觉悬空，不影响物理。

## 4. 场景预设（异常注入用）

`ros2 launch arm_grasp_sim classify_sim.launch.py blocks_preset:=<名> z_grasp:=<值>`

| 预设 | 注入的异常 | 期望分类 |
|---|---|---|
| `normal` | 无 | 6 placed |
| `empty_grid` | 撤掉 2 个物体 | 2 `skipped_empty` + 4 placed |
| `unknown_obj` | 把 1 件换成红色物体（不在色带内） | 1 `skipped_unknown` + 5 placed |
| `miss_grasp` | 只放 2 件 + 抬高抓取位使指爪落空 | `grasp_failed`，任务不中断 |
| `unreachable` | `z_grasp:=0.005` 低于几何可达下限 | 2 `unreachable`，且**不重试** |
