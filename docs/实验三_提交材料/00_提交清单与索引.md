## 一键复现

```bash
# 构建
cd ~/arm_grasp_ws && colcon build --symlink-install && source install/setup.bash

# 正常场景全自动验收（带 GUI，起来即自动跑完 6 格，约 5~6 分钟）
bash ~/exp3_gui_run.sh

# 无 GUI 的验收跑
ros2 launch arm_grasp_sim classify_sim.launch.py

# 异常场景批跑（4 个预设，产物在 ~/classify_logs/exceptions/）
bash ~/arm_grasp_ws/src/arm_grasp_sim/scripts/run_exceptions.sh
```

结果文件：`~/classify_logs/task_log.json`，末条为 `summary`。
